# HSK 1級 練習サイト —— 维护指南（老师用）

这是根据 **HSK（一级）H11004 卷**做成的练习网站。学生看到的界面全部是日语，适合日本大学生使用。
不需要服务器：双击 `index.html` 就能用，也可以直接放到 GitHub Pages。

---

## 1. 网站有什么功能

| 功能 | 说明 |
|---|---|
| **練習モード（练习模式）** | 一题一题做。可以选「全問」「聴解のみ」「読解のみ」或某一个部分。 |
| 出题顺序 | 学生可以选「原題の順番」（按原题顺序）或「ランダム」（随机）。 |
| 答错时 | 马上显示正确答案和日语解说；**只有选了正确答案才能进入下一题**。 |
| 日语解说 | 每道题答完后（答对、答错都显示）：①なぜ○が正解？（为什么是正确答案）②ほかの選択肢が違う理由（其他选项为什么不对）③覚えておきたい表現（值得记住的词语和语法）④听力原文（拼音・汉字・日语译文）或阅读题的日语译文。 |
| 结束后 | 显示「一次就答对」的题数；可以只重做答错的题。 |
| **試験モード（考试模式）** | 和正式考试一样：先播放整段听力录音（约 15 分钟）边听边答，再做阅读（17 分钟倒计时，时间到自动交卷）。交卷后显示分数（200 分满分，120 分合格线）和全部题目的答案、解说。 |
| 播放器 | 底部固定。显示状态（再生中・一時停止中・停止中・再生終了）、进度条、停止键、语速 0.5～2 倍。 |
| 显示设置 | 右上角：拼音显示/隐藏、字号 A−/A＋。支持深色模式。 |
| 记录保存 | 自动保存在学生自己的浏览器里（换电脑、换手机、无痕模式不会保留）。 |

已在 Chromium（Chrome / Edge 同内核）上实际测试；Firefox 和 Safari 没有实测，但只用了这些浏览器都支持的普通功能。

## 2. 文件结构

```
claude/
├── index.html          网站首页（首页说明文字在 <template id="tpl-home"> 里，可以直接改）
├── check.html          数据检查页（浏览器打开即可）
├── 维护指南.md          本文件
├── css/style.css       样式
├── js/
│   ├── core.js         试卷登记、拼音写法解析
│   ├── player.js       播放器（全站只用一个）
│   ├── app.js          页面逻辑
│   └── validate-core.js  检查规则（check.html 和 tools/check.js 共用）
├── data/
│   ├── manifest.js     试卷清单（加新试卷只改这里）
│   ├── parts.js        各部分的日语名称和说明（同一级别所有试卷共用）
│   └── H11004.js       H11004 卷的全部题目、答案、原文、译文、解说
├── img/H11004/         题目图片（44 张）
├── audio/H11004/
│   ├── H11004_听力录音.mp3   原始整段录音（考试模式用，未改动）
│   └── clips/          每道题的录音片段（练习模式用）：q01～q20，例题 ex1a ex1b ex2 ex3 ex4
└── tools/check.js      数据检查工具（Node 版，更详细）
```

## 3. 上传到 GitHub Pages

1. 把整个 `claude` 文件夹放进仓库（已经放在 `tcll1988/HSKQ` 仓库的 `claude/` 里）。
2. 仓库 → **Settings → Pages** → Source 选 **Deploy from a branch**，Branch 选 `main`、文件夹选 `/ (root)` → Save。
3. 1～2 分钟后，网址是：`https://tcll1988.github.io/HSKQ/claude/`
4. 把这个网址发给学生即可。

> 注意：仓库是**公开**的，HSK 真题、图片和录音的著作权属于出题机构（汉考国际）。只在课堂内使用时问题较小，但请留意不要大范围公开传播。

## 4. 修改内容

所有题目内容都在 `data/H11004.js` 里，用记事本或 VS Code 打开即可修改。每道题的写法：

```js
{ no: 16, options: {
    A: { text: '[后天|hòutiān]', ja: 'あさって' },
    B: { text: '[下|xià][个|ge][星期|xīngqī]', ja: '来週' },
    C: { text: '[下|xià][个|ge][月|yuè]', ja: '来月' } },
  answer: 'C', audio: 'clips/q16.mp3', t: [655.6, 675.3],
  script: [ { zh: '下个月，我去北京。', py: 'Xià ge yuè, wǒ qù Běijīng.', ja: '来月、私は北京へ行きます。' }, … ],
  note: '…为什么 C 是正确答案…',
  others: { A: '…A 为什么不对…', B: '…B 为什么不对…' },
  point: '…值得记住的词语、语法…' },
```

| 想改什么 | 改哪里 |
|---|---|
| 答案 | `answer:`。判断题写 `'T'`（✓）或 `'F'`（✗），选择题写 `'A'`～`'F'`。改完后学生的对错会自动按新答案重新判断。 |
| 解说 | `note`（为什么正确）、`others`（其他选项为什么不对，可省略）、`point`（要点）。 |
| 带拼音的文字 | 写成 `[汉字|pinyin]`，标点写在方括号外面，例：`[你|Nǐ][好|hǎo]！` |
| 填空题的空格 | 写三个下划线 `___` |
| 听力原文 | `script` 里的 `zh`（汉字）、`py`（拼音）、`ja`（日语译文）、`who`（说话人：男/女/问） |
| 各部分的日语说明 | `data/parts.js` 里的 `title`、`short`、`instruction` |
| 首页文字、使用方法 | `index.html` 里 `<template id="tpl-home">` 中间的文字 |
| 图片 | 用**同样的文件名**覆盖 `img/H11004/` 里的图片 |
| 录音 | 用**同样的文件名**覆盖 `audio/H11004/` 里的 mp3 |

**注意**：每个字符串用英文单引号 `'…'` 包起来；如果内容里本身有单引号（例如 `nǚ'ér`），要写成 `\'` 或者整个字符串改用双引号。改完后请打开 `check.html` 检查一遍。

没有录音的题目把 `audio:` 写成 `null`，网页上会显示「音声なし」。

## 5. 加一套新试卷（例如 H11005）

1. 复制 `data/H11004.js`，改名为 `data/H11005.js`，把里面的 `id: 'H11004'` 改成 `'H11005'`，`audioRoot`、`imgRoot` 改成新文件夹，再逐题修改内容。
2. 图片放进 `img/H11005/`，录音放进 `audio/H11005/`。
3. 打开 `data/manifest.js`，把清单改成：`HSK.manifest = ['H11004', 'H11005'];`
4. 打开 `check.html` 检查。首页会自动多出一张试卷卡片。

> 考试模式需要 `fullAudio`（整段录音的文件名）和每道听力题的 `t: [开始秒数, 结束秒数]`（用来在考试时高亮「现在是第几题」）。没有 `t` 也能用，只是不会高亮。

## 6. 学生的记录是怎么保存的

- 保存在学生浏览器的 localStorage 里，不会上传到任何地方，老师看不到。
- 练习模式只保存「这道题第一次选了哪个选项」（键是 `试卷:题号`，例如 `H11004:16`）。对错是每次按现在的答案重新判断的，所以**老师改了答案，学生的统计会自动更正**。
- 练习到一半关掉页面，下次打开会从同一题继续。
- 考试模式保存答案、听力的播放位置和阅读的截止时间；中途关掉页面可以继续。
- 首页「この試験の練習記録をすべて消す」可以清除练习记录（要连点两次确认）。

## 7. 检查工具

- **浏览器版**：打开 `check.html`。检查格式、题号重复、答案是否在选项里、拼音写法、填空的空格、图片和录音是否读得到。
- **Node 版**（更详细）：在 `claude` 文件夹里运行 `node tools/check.js`。另外还查：manifest 和 data 文件夹是否一致、0 字节文件、不是 MP3 的文件、内容完全一样的录音（可能拿错文件）、没有被用到的图片和录音。
- 交付前做过反向测试：故意改错 10 处（题号重复、答案写成 G、拼音括号不成对、填空少了 ___、0 字节录音、假 MP3、缺图片、录音重复、多余文件、未登记的试卷），全部被检查出来。

## 8. 制作记录（请老师确认）

### 资料来源与处理
- 题目、答案、听力原文全部取自 `H11004_教师版（含听力原文和答案）.pdf`（字体完整，没有水印）。`学生题本.pdf` 和 `答案.pdf` 有缺字和 my-hsk.com 水印，只用来对照。
- **答案**：教师版答案页和 `答案.pdf` 的 40 个答案逐一比对，完全一致；又逐题对照听力原文和图片确认，没有发现矛盾，**没有修改任何答案**。
- **拼音**：阅读部分和听力第四部分选项的拼音来自 PDF，57 条文字用程序与 PDF 逐字核对，汉字和拼音全部一致。
- **图片**：从教师版 PDF 按原图位置裁剪，共 44 张。
- **录音**：三个 mp3（`听力录音.mp3` 192kbps、`其他版本/` 里两个 16～19kbps 的低音质版本）内容和时长相同，网站使用音质最好的 `H11004_听力录音.mp3`。按静音位置切成 20 道题 + 5 段例题，每段包含「题号＋两遍内容」。各段时长与内容字数成正比，顺序一致。`其他版本/` 的两个文件没有放进网站。

### 补加的内容（原 PDF 没有，请老师过目）
- 听力原文（第 1～20 题和例题）的**拼音**。其中第 9 题「一点十分」写作 `yī diǎn`（未按变调写 yì）、第 19 题「回来」写作 `huílai`（轻声），如果课堂上的标注习惯不同，请在 `data/H11004.js` 里修改。
- 全部**日语译文**和**日语解说**（note / others / point）。
- 各部分的日语题目说明（`data/parts.js`）。

### 没有做的验证
- 没有用语音识别逐条听写录音，只核对了数量、顺序、时长与字数的比例；建议老师抽听几题确认切分位置。
- 只在 Chromium 系浏览器（Chrome / Edge）实测；Firefox、Safari（含 iPhone）没有实测。
