# HSK（1級）公式過去問演習サイト · H11004（Gemini 版）

日本の大学生向けに設計された **新漢語水平考試 HSK（1級）過去問 H11004** のWeb演習サイトです。  
GitHub Pages や任意の静的ホスティングですぐに公開・利用できるよう、`gemini/` 直下にビルド済みの静的ファイル（`index.html` + `assets/`）を配置し、`gemini/source/` に編集可能な React + TypeScript + Tailwind CSS ソースコードを収録しています。

## 主な機能

- **全ページ日本語UI**（問題文・ピンイン・リスニング原文は中国語 `lang="zh-CN"` で正確に表示）
- **練習モード（1問ずつ定着・正解必須ステップ方式）**
  - **原題どおり（出題順）** ／ **ランダム順（シャッフル）** を自由に選択可能
  - 範囲選択：全40問 ／ リスニングのみ（20問） ／ リーディングのみ（20問）
  - **間違えると即座に正解と「なぜこれが正解？」の詳しい日本語解説を表示**し、正しい選択肢を選び直すまで次の問題へ進めない仕組み
- **試験モード（模擬試験）**
  - **本番どおり（出題順・14:37 通し公式音声＋自動追従）** ／ **ランダム順（シャッフル・各問音声再生）** に対応
  - 35分タイマー・40問解答シート・200点満点（120点合格）の公式基準スコアレポート
  - 採点後に **全40問の詳しい日本語解説（正解の根拠＋日本語訳＋日本人学習者向けポイント）** を表示
- **頻出単語フラッシュカード（重要30語）**（中国語読み上げ・例文・出題問題へのリンク付き）
- **主要ブラウザ完全対応**（Chrome / Safari / Edge / Firefox・スマートフォン対応）

## フォルダ構成

```text
gemini/
├── index.html          # そのまま GitHub Pages 等で開ける静的エントリポイント
├── assets/             # ビルド済み JS / CSS・原題イラスト44枚・公式音声 H11004.mp3
├── source/             # 開発用ソースコード（React + TypeScript + Vite + Tailwind CSS）
└── README.md
```

## ローカル開発（ソースを編集する場合）

```bash
cd gemini/source
npm install
npm run dev
```
